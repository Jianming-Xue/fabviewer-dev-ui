## 一、项目定位

**vui** — FabViewer（半导体工厂日志检索/诊断平台）的前端。当前完成：应用壳 + 登录/修改密码 + 三个业务模块（配置 / 用户和安全 / 日志检索，全部 Mock 驱动）。后端 `.NET` 服务（`../webui/`）尚未对接。

## 二、快速上手

```bash
npm install        # Node 24 / npm 11
npm run dev       # :5173，默认 VITE_MOCK=true，无需后端
npm run type-check / lint / build   # 全绿
```

- **换 Mock/真实后端**：`.env.development` 的 `VITE_MOCK`
- 登录：任意非空用户名/密码；修改密码：旧密码非空，新密码限制**按登录策略**（无策略退化 6~18 位，2026-10-20 晚改版；mock 登录 admin→标准策略 P001、test→强策略 P002、其余不挂=演示退化）
- 账号：`MORRISLI` 可复现记住用户名；权限演示账号 `admin`（全功能）/ `test`（仅角色+Server Hang）
